# 🔬 Laboratory Methodology

## Purpose

The laboratory follows a controlled and repeatable methodology for
studying defensive cybersecurity operations.

## 1. Prepare

Build or configure the laboratory environment.

## 2. Simulate

Generate controlled security-relevant activity.

## 3. Collect

Identify the telemetry and logs generated by the activity.

## 4. Detect

Determine whether existing security controls detect the activity.

## 5. Triage

Evaluate the alert and determine whether it represents suspicious
or malicious activity.

## 6. Investigate

Analyze:

- source;
- destination;
- user;
- process;
- timestamp;
- network activity;
- related events;
- indicators.

## 7. Respond

Perform appropriate defensive actions within the controlled
laboratory environment.

## 8. Document

Create an incident report containing the evidence, timeline,
investigation and response.

## 9. Improve

Evaluate whether:

- detection rules should be improved;
- additional telemetry is required;
- false positives can be reduced;
- response procedures can be improved.
